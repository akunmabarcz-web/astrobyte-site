Astrobyte

A desktop tool that runs on one computer and automates the publishing workflow of the Astro and Tech YouTube channel: scheduling its own uploads, reading its own statistics, and keeping its own comment section clean.

Astrobyte is not a service and not an app you sign up for. It is a script-driven tool operated by the owner of @astroandtech on the owner's own machine. It talks to the YouTube Data API and the YouTube Analytics API using the owner's own Google authorisation, and it only ever touches that one channel.

What it does

Publishes and schedules

Uploads finished videos to the channel with their title, description, tags and thumbnail, and places them on a publishing schedule so each one goes public at a planned time.

Reads the channel's own analytics

Pulls views, watch time, subscriber movement and per-video retention for the channel it belongs to, then turns them into a short daily and weekly report.

Moderates comments

Reads comment threads on the channel's own videos and hides obvious spam. Draft replies to real comments are written for the owner to read and approve, never posted automatically.

Prepares publish-ready files

Assembles episodes from a script, generated images and narration, checks the audio and subtitle timing, and writes the caption for each platform before anything is uploaded.

What it is not

  • Not a public service, and not a website anyone logs into.
  • Not an app with user accounts. There is exactly one user, the channel owner.
  • Not a data collection product. It collects nothing from anyone, and it has no third-party users.
  • Not affiliated with, endorsed by, or sponsored by YouTube or Google.

How it fits together

Each run is driven by a short, human-readable task file. The tool authenticates with the channel owner's own Google account, performs the requested step against that channel's own data, and writes a log so the result can be checked afterwards.
