What it does

Four jobs, all of them on the owner's own channel, all of them through Google's own APIs.

Publishes and schedules

Uploads a finished video with its title, description, tags and thumbnail, then places it on a scheduled time so it goes public when planned rather than the moment it is uploaded. It keeps its own queue per day, so a batch is never published twice or skipped.

Reads the numbers

Views, watch time, average view duration, subscriber movement, and which videos moved since the last reading. A scheduled video showing zero views is labelled normal rather than reported as a drop.

Keeps comments clean

Hides obvious spam on the channel's own videos. Replies to real comments are written as drafts for the owner to approve, never posted on their own.

Builds the episode

Turns a written script into a finished vertical video: narration, music, moving images, and captions aligned to the spoken words and checked before the file is accepted.

What it is not

Worth stating plainly, because most tools that reach into Google's APIs are the opposite of this.

  • Not a service and not a site anyone signs into. There is no account system and no login page.
  • Not a product for other people. Exactly one operator, the owner of the channel.
  • Not a data collection tool. It collects nothing from anyone and has no third-party users.
  • Not affiliated with, endorsed by, or sponsored by YouTube or Google.

How a run works

No server in the middle, no dashboard, no daemon running in the background. The tool runs when the owner starts it.

  1. 01 A task file is readEach run is described in a short readable file: which episode, which step, which platform. Nothing is hard-coded into the tool itself.
  2. 02 The owner authorisesA Google OAuth token granted once, on that machine, for that one channel. A missing or expired token stops the run instead of working around it.
  3. 03 The work goes through official APIsUploading, analytics reads and comment moderation all use Google's own endpoints, for the owner's own channel, and for nothing else.
  4. 04 The result is loggedEvery run records what it did and what came back, so the outcome can be checked afterwards instead of taken on trust.
