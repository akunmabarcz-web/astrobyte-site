Privacy Policy

Astrobyte desktop tool · Effective 22 October 2026

Astrobyte ("the tool") is a private desktop automation tool operated by the owner of the Astro and Tech YouTube channel (@astroandtech). This policy explains what data the tool accesses, why, and how it is handled.

1. Who uses the tool

Exactly one person: the owner of the channel, on their own computer. There is no sign-up, no public interface, and no other users. The tool never collects personal data from the public.

2. What data the tool accesses

Only data belonging to the channel owner's own YouTube channel, via Google's official APIs and only after the owner grants access on the Google consent screen:

  • YouTube Data API v3 — the channel's own video list, titles, view/like counts, publish status, and the channel's own comments (to hide spam).
  • YouTube Analytics API — the channel's own aggregate metrics (views, estimated minutes watched, average view duration, subscribers gained).
  • Upload access — used to upload the owner's own videos to the owner's own channel and to set a scheduled publish time.

The tool does not access Gmail, Drive, Contacts, Calendar, or any other Google service, and it does not access any other person's channel or data.

3. How the data is used

  • To publish videos the owner has already produced.
  • To produce a short private status report for the owner (channel views, subscribers, scheduled videos).
  • To hide obvious spam comments on the owner's own videos.

No automated decisions with legal effect are made, and no profiling or advertising uses the data.

4. Where the data goes

  • Data stays on the owner's own computer. The tool has no server and no database in the cloud.
  • Nothing is sold, rented, shared, or disclosed to third parties. No advertising or analytics third parties are involved.
  • No human other than the channel owner reads the data.
  • Transfers to Google's APIs are protected by HTTPS.

5. Google user data and Limited Use

Astrobyte's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Google user data is used only to provide the features described above; it is not transferred to others, not used for advertising, and not used to train machine-learning models.

6. Storage and retention

  • OAuth credentials (access and refresh tokens) are stored in a local file on the owner's computer.
  • Statistics snapshots are stored locally on the owner's computer.
  • Data is kept only while the tool is in use. Deleting the local files removes it entirely.

7. Your control and revocation

The channel owner can revoke the tool's access at any time at myaccount.google.com/permissions. Revoking access immediately stops all API access; the local files can then be deleted for full removal.

8. Children

The tool is not directed to children and is not offered to the public.

9. Changes

If this policy changes, the updated version will be published on this page with a new effective date.
