Features

Everything Astrobyte does, in the order it does it. Each feature works against one channel only, using that channel owner's own authorisation.

Publishing and scheduling

  • Uploads a finished video file to the channel with its title, description, tags and category.
  • Sets the custom thumbnail on the uploaded video.
  • Places the video on a scheduled publishing time so it becomes public when planned, instead of the moment it is uploaded.
  • Keeps its own queue file per day, so a batch of episodes is never published twice or skipped.
  • Reads back the upload result and records the video identifier, so later steps can find the video again without guessing.

Channel analytics and reporting

  • Reads views, watch time, average view duration and average view percentage for the channel's own videos through the YouTube Analytics API.
  • Tracks subscriber movement and reports which videos gained or lost views since the last reading.
  • Distinguishes public, unlisted and scheduled videos. A scheduled video showing zero views is normal and is labelled that way rather than reported as a drop.
  • Produces a short daily brief and a longer weekly review, with the numbers behind each claim.
  • Keeps a snapshot history so today's figures can be compared against previous days.

Comment moderation

  • Reads the comment threads on the channel's own videos.
  • Flags and hides obvious spam and scam comments. This changes the comment's moderation status on the channel's own video.
  • Writes draft replies to genuine comments for the owner to review. Nothing is posted to a viewer without the owner reading it first.
  • Records what was hidden and what was drafted, so the decisions can be reviewed later.

Episode assembly

  • Turns a written script into a finished vertical episode: narration, background music, images with slow movement, and burned-in captions.
  • Aligns every caption line to the point in the narration where it is actually spoken, and checks the result before the file is accepted.
  • Normalises audio loudness to a consistent level across episodes.
  • Writes per-platform captions, with a fixed hashtag set and a length limit per platform.

What Astrobyte deliberately does not do

  • It does not create or manage accounts for other people.
  • It does not post replies to viewers on its own. Drafts are for the owner to approve.
  • It does not read or write data belonging to any channel other than its own.
  • It does not sell, share or publish any data, because it has no third-party data to begin with.
